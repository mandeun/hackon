# 스토어 반려 대장 — 왜 막히고, 어떻게 넘나

반려 메일이 오면 **여기에 한 줄 더한다**: 날짜 · 조항 · 그쪽이 쓴 문장 그대로 · 우리가 고친 것 · 다시 낸 날 · 결과.
다음 사람(또는 다음 앱)이 같은 데서 안 넘어지게 하는 게 이 문서의 일이다.

HACK:ON 앱은 hackon.kr 을 여는 껍데기다. 그래서 반려 사유 대부분은 «웹을 감쌌을 뿐» 으로 읽히는 데서 온다.
아래 «우리 상태» 는 이 저장소(server.js·화면 파일)를 보고 적었다. 껍데기 쪽 코드는 이 저장소에 없으니 그 칸은 «껍데기에서 확인» 이라 적는다.

## App Store — 자주 막히는 조항

| 조항 | 무엇 때문에 | 넘는 법 | 우리 상태 |
|---|---|---|---|
| **4.2 최소 기능** | 웹사이트를 감싼 것뿐인 앱 | 앱에만 있는 것: 푸시 알림, 공유 시트, 달력에 넣기, QR 찍어 체크인, 오프라인 안내 화면. 심사 메모에 «앱에서만 되는 것» 을 목록으로 적는다 | 껍데기에서 확인. **가장 큰 위험** |
| **2.1 앱 완성도** | 빈 화면, 로그인 못 함, 죽음, 깨진 링크 | 심사 메모에 «바로 보는 길» 을 적는다(예: 첫 화면 → 열린 대회 → 신청). 로그인이 필요하면 데모 계정. 빈 서버로 심사하지 않게 공개 대회 하나를 올려 둔다(연습용 말고) | 연습용 대회는 3일 뒤 저절로 지워지니 **심사용 대회는 연습용으로 열지 않는다** |
| **5.1.1(v) 계정 삭제** | 가입은 되는데 앱 안에서 지울 수 없음 | 앱 안 «계정 삭제» + 웹 안내 주소 | 됨 — 앱이나 hackon.kr/app 에서 로그인 → 아래 «대회» 탭 → 위쪽 «계정 삭제» → «탈퇴» 라고 적고 지우기, 그리고 /delete-account |
| **4.8 Sign in with Apple** | 카카오·구글 로그인만 있음 | 같은 화면에 애플 로그인 | 됨 — LOGINS.apple |
| **1.2 사용자 생성 콘텐츠** | 남이 쓴 글이 보이는데 신고·차단·걸러내기가 없음 | 신고, 차단, 운영자 내리기, 이용약관에 «불쾌한 글 금지» | 됨 — 신고·차단·운영자 내리기, 이용 규칙 /terms(첫 글 전 동의 창이 가리킨다) |
| **5.1.1 개인정보** | 처리방침이 없거나 실제와 다름 | 처리방침 주소, 앱 개인정보 «라벨» 과 실제 수집이 같아야 | /privacy. 라벨은 listing.md «수집하는 것» 과 맞출 것 |
| **2.3 메타데이터** | 스크린샷이 실제 앱과 다름, 다른 플랫폼 이름(안드로이드 등) 노출 | 실제 화면만, 아이폰 크기 | shots.py 로 찍는다 |
| **3.1.1 인앱 결제** | 디지털 상품을 앱 밖 결제로 판매 | 앱 안에서 돈을 받지 않는다. 협찬·외주는 «사람끼리 직접» 이라고 화면에 적는다 | 됨 — «이 앱은 돈을 받지 않습니다» |
| **5.2 지식재산** | 남의 상표·로고 | 협찬사 로고는 그 회사가 올린 것만 | 됨 — 확인된 협찬사만 이름이 오름 |
| **4.0 디자인** | 아이패드에서 깨짐, 가로 화면 깨짐 | 아이패드 지원을 끄거나 제대로 그린다 | 껍데기에서 확인 |

## Google Play — 자주 막히는 것

| 정책 | 무엇 때문에 | 넘는 법 | 우리 상태 |
|---|---|---|---|
| **데이터 보안 양식** | 양식과 실제 수집이 다름 | listing.md «수집하는 것» 과 한 줄씩 맞춘다 | 맞출 것 |
| **계정 삭제** | 앱 밖 삭제 주소가 없음 | 웹에서 지우는 주소 | /delete-account — 지우는 길은 위 5.1.1(v) 줄과 같은 문장 |
| **비공개 테스트 12명·14일** | 개인 개발자 계정은 프로덕션 전에 테스터 12명이 14일 써야 | 동아리원 12명에게 테스트 링크를 돌린다. 10/31 참가자가 딱 맞다 | 준비할 것 |
| **웹뷰 스팸(최소 기능)** | 웹사이트만 띄움 | App Store 4.2 와 같은 대처 | 껍데기에서 확인 |
| **타깃 API 수준** | 오래된 targetSdk | 그해 기준으로 올린다 | 껍데기에서 확인 |
| **사용자 생성 콘텐츠** | 신고·차단 없음 | App Store 1.2 와 같음 | 됨 |

## 심사 메모(App Review Notes) 틀

```
HACK:ON 은 동아리·학교의 작은 해커톤을 여는 도구입니다.
바로 보는 길: 첫 화면 → «열린 대회» 의 [심사용 대회 이름] → 참가 신청(이름·이메일만).
대회 열기: 아래 «대회 열기» → 이름 하나 → 운영 화면.
앱에서만 되는 것: 알림(마감 1일 전), 공유 시트, 달력에 넣기, QR 체크인.
로그인: 없어도 모든 기능을 볼 수 있습니다. 로그인하려면 Sign in with Apple.
계정 삭제: 앱이나 hackon.kr/app 에서 로그인 → 아래 «대회» 탭 → 위쪽 «계정 삭제» → «탈퇴» 라고 적고 지우기.
신고·차단: 대회 페이지·만든 것·외주 글마다 «신고» 와 «차단».
결제: 앱은 돈을 받지 않습니다. 협찬은 주최자와 협찬사가 직접 합니다.
```

## 다시 내기 전 확인

- [ ] 심사용 공개 대회가 하나 열려 있고 **연습용이 아니다**(연습용은 3일 뒤 지워진다)
- [ ] 첫 화면에서 세 번 안에 신청까지 간다
- [ ] 로그인 없이 다 볼 수 있다
- [ ] 계정 삭제·신고·차단이 실제로 눌린다
- [ ] 스크린샷이 지금 화면과 같다
- [ ] 개인정보 라벨 = 처리방침 = 실제 수집
- [ ] 앱에서만 되는 것이 최소 둘 이상 실제로 돈다(껍데기)
