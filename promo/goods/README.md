# HACK:ON 굿즈 — «켜다» 하나로 묶는다

원본(고칠 수 있음): Figma «HACK:ON 10/31 데모데이 홍보물» → «굿즈» 페이지
https://www.figma.com/design/oQW73D8yBF1ShfEOsp7nlD

컨셉: 노랑이는 **콘센트** 이고, 해커온은 **켜는 곳** 이다. «NO» 라고 생각한 걸 «너랑» 켠다.
그래서 굿즈는 전부 «켜다·꽂다·ON» 중 하나를 말한다. 노랑이는 앰버, 단추·강조는 라임, 바탕은 먹.

| 무엇 | 언제 주나 | 왜 |
|---|---|---|
| ON 스위치 스티커 | 신청하고 온 사람 전원 | 노트북에 붙는 순간 «켜 둔 사람» 표시가 된다 |
| 완주 원형 스티커 | 발표까지 한 팀만 | 돈 안 드는 «자랑거리». 완주 기록증과 같은 말 |
| NO → 너랑 스티커 | 현장 테이블에 깔아 둠 | 이름의 뜻을 설명 없이 한 장으로 |
| 같이 꽂자(콘센트 2구) | 짝 신청·팀 매칭된 사람 | 같이 온 사람을 다시 데려오게 |
| 노트북 스티커(상표) | 크루·멘토·심사위원 | 가장 오래 보이는 자리 |
| 티셔츠 뒷면 «끄지 말고, 너랑 켜자» | 운영진·크루 | 현장에서 누구한테 물을지 보이게 |
| 현장 명찰 | 전원 | 이름 크게, 역할(만드는 사람·멘토·심사) 라임 띠 |
| ON 키캡 | 우승팀·협찬 기념 | 비싸 보이지만 한 개 수천 원 |

순서: 10/31 에는 **스티커 넷 + 명찰** 만(인쇄소 스티커 1장에 모아 찍으면 수십만 원 안쪽). 티셔츠·키캡은 크루 1기 때.
