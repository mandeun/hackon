# HACK:ON 광장 (로블록스)

해커온의 열린 대회를 로블록스 광장에 부스로 세운다. 노랑이 동상, 데모 무대, 대회 부스(10분마다 hackon.kr 공개 목록에서).

## 돌리는 법
1. [Rojo](https://rojo.space) 설치 → 로블록스 스튜디오에 Rojo 플러그인
2. 이 폴더에서 `rojo serve` → 스튜디오에서 Connect
3. 게임 설정 → 보안 → **HTTP 요청 허용** 켜기(부스가 hackon.kr 을 읽는다)
4. 플레이 → 스폰(라임) 앞에 노랑이, 뒤에 데모 무대, 둘레에 대회 부스

> 이 스크립트는 이 저장소의 작업 환경에 로블록스 스튜디오가 없어 **돌려 보지 못했다.** 처음 열 때 출력 창의 경고를 본다.

## 지키는 것
- **게임 밖 링크를 단추로 만들지 않는다.** 로블록스는 게임 안에서 외부 사이트로 보내는 것을 막는다(13세 미만 포함). 부스엔 «무엇이·언제»만, 신청은 각자 hackon.kr 에서.
- 연락처·열쇠는 읽는 응답에 애초에 없다(공개 목록만 읽는다).
- 목록을 못 읽으면 부스를 지우지 않는다 — 모름을 없음으로 그리지 않는다.

## 돈은 로블록스 안의 것으로
우리 코인을 만들지 않는다. 로블록스 안에서는 **Robux**(게임 패스·아이템)가 이미 있고, 만든 사람은 **DevEx** 로 현금화한다.
해커온 굿즈(ON 스위치·노랑이 모자)를 로블록스 아이템으로 내는 것이 «가상세계 + 굿즈» 의 가장 짧은 길이다.
