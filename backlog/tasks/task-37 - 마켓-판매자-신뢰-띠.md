## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
차별점. Gumroad·크몽의 신뢰 근거는 구매 후기뿐이고, 다른 곳의 데모는 판매자가 따로 만든 것이다(Envato 도 라이브 프리뷰는 선택). HACK:ON 에는 **마감이 지난 대회에서 실제로 돌아간 주소와 «며칠째 살아 있나»**(showcase()·ageOf), 완주·매너·실력 동료 평가, 받은 칭찬이 이미 있다.
상세 페이지에 한 줄: 완주 N · 매너(3건 이상일 때 숫자) · 받은 칭찬 상위 · 데모 N일째 열림. 새로 세지 않고 profile() 을 그대로 쓴다. 기록이 없으면 «처음» — 0 으로 그리지 않는다.
