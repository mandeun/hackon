# 해커온 브랜딩·홍보 — 듀오링고식, 2030 여성까지 (2026-10-05)

> 한 줄: **노랑이를 «로고»가 아니라 «성격 있는 사람»으로 키우고, 사람들이 해커온에서 한 것을 «한 장으로 자랑»하게 만든다.** 개발 얘기 대신 «퇴근 후 한 시간에 만든 내 것»을 보여 준다.

## 1. 듀오링고에서 가져올 것과 안 가져올 것

| 듀오링고 | 해커온에 옮기면 | 상태 |
|---|---|---|
| 부엉이 Duo가 **기분·말버릇·밈**이 있는 캐릭터. 앱 아이콘이 아니라 사람처럼 군다 | 노랑이(콘센트 머리 + 전선 몸). 말버릇: «불 들어왔어요», «플러그만 꽂혀 있어요». 사람을 반기는 쪽으로만 | `/me` 노랑이 한마디 ✅ |

## 2. 2030 여성에게 — 무엇이 막고, 무엇이 끄나

막는 것(가정, 첫 모임에서 물어 확인할 것)
- «해커톤 = 밤샘·남초·개발자끼리». 들어가면 나만 모를 것 같다.
- 결과물이 «내 삶과 상관없는 데모».
- 커뮤니티의 거친 말투.

끄는 것
- **내 일·내 삶에 바로 쓰는 것**: 청첩장, 가계부, 스마트스토어 주문 정리, 독서 기록, 반려동물 병원 기록, 여행 일정표 → 첫 화면 예시 여섯 ✅
- **혼자 와도, 처음이어도, 낮 두 시간** → 첫 화면 한 줄 ✅ (팀원 추천·혼자 신청은 이미 있음)
- **안전**: 욕설 거름·차단·신고 24시간 → App Store 1.2 작업 ✅
- **예쁜 한 장**: 자랑 카드, 포스터, 굿즈(스티커·멀티탭) → 카드 ✅, 굿즈는 `/club`

## 3. 채널과 순서 (홍보비 최소)

1. **인스타 @hackon.kr** — 주 3회. ① 노랑이 짧은 영상 ② «이번 주 이걸 만들었어요» 참가자 결과물(자랑 카드 리그램) ③ 할인·새 모델 카드뉴스(소식에서 그대로).
2. **«친구 한 명 데려오기»** — 신청 뒤 «같이 올 사람 있으세요 → 초대 링크» 가 이미 있다 ✅. 포스터·인스타 문구에 «둘이 오면 같은 팀» 을 앞세운다.
3. **협업 계정** — 바이브코딩·노션·업무 자동화 다루는 여성 크리에이터 3~5명에게 «하루 심사위원» 자리(돈 대신 이름과 자리). 자리 매칭(`/card`)으로 초대.
4. **모임 장소** — 카페·공유오피스 낮 시간(13–15시). 10/31 선릉이 첫 판.
5. **당근 모임·오픈채팅 대표** 협조 — 이미 계획에 있음.

## 4. 말투 (노랑이 목소리)

- 반말·존댓말 섞지 않는다. **짧은 존댓말 + 장난 한 스푼**.
- 금지: 겁주기(«안 하면 뒤처져요»), 죄책감(«3일째 안 왔네요»), 개발자 은어로 놀리기.
- 예: «아직 플러그만 꽂혀 있어요. 아무거나 하나 눌러 주면 제가 켜져요.» / «오랜만이에요! 쉬어도 모은 건 그대로예요.»
