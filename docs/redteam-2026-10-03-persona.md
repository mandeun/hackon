# 레드팀 — 가상 사람 다섯 (2026-10-03)

> 나는 이 시스템을 뚫으려는 공격자다. 다섯 사람이 되어 쳤다: 4050 사장님 · 첫 대회 학생 · 악성 도배꾼 · 화면 읽기 사용자 · 느린 폰.

## 발견

### [중간] 전각 숫자·다른 줄표·0폭 공백으로 연락처 거름 통과
- 위치: `server.js` `looksContact`
- 재현: 게시판 본문 `０１０-１２３４-５６７８` · `010‑1234‑5678`(U+2011) · `010​1234​5678`(0폭 공백) → 201
- 결과: 공개 글·소개·카드에 전화번호가 실린다
- 수정(됨): `unhide` — NFKC 로 펴고 0폭 글자를 지우고 줄표를 «-» 로 모은 뒤 본다. 날짜(«2026년 10월 31일»)는 안 잡는다

### [중간] 한 사람이 한 장을 제안 50개로 메워 남이 못 낸다
- 위치: `editPropose`
- 재현: 같은 IP 로 제안 52번 → 51번째부터 429(장 전체 상한), 다른 사람도 못 냄
- 수정(됨): 한 사람(소금 친 IP 해시) 한 장에 기다리는 제안 3개

### [중간] 메뉴 판에서 Tab 이 뒤 화면으로 샌다
- 재현: 메뉴를 열고 Tab 40번 → 17번이 판 밖(뒤 화면 단추)
- 결과: 키보드·화면 읽기 사용자가 판 뒤에서 길을 잃는다
- 수정(됨): 판 안에서 돌게(Shift+Tab 포함)

### [낮음] 전각 «ＨＡＣＫＯＮ» 닉으로 사칭
- 수정(됨): 닉도 펴서 본다

### [낮음] 줄바꿈 2500개 본문
- 수정(됨): 넷 이상 이어진 줄바꿈은 셋으로

## 뚫지 못한 것
- 0폭 공백 넣은 «해​커온 운영자» 닉(«운영자» 가 걸림), «공일공 일이삼사…», «o1o.1234…»
- 공구함 2MB 붙여 넣기 0.05초, 한 줄 50만 자 0.02초 — 정규식 폭주 없음. 서버 요청 0
- 공구함 글자 200% 에서도 가로 밀림 없음
- 뉴스 «바로 해 보기» 명령: `github.com/a/b; rm -rf /` 같은 주소는 명령을 안 만든다
- 꺼진 망: 게시판·달력·혜택은 «모릅니다» 를 «없음» 과 다르게 그린다(이전 검사)

## 남은 위험
- IP 해시 상한은 휴대폰 데이터를 껐다 켜면 우회된다. 다음: 로그인 계정 기준.
